Quiver Portable

Run QuiverPortable.exe on 64-bit Windows. The Data folder beside the launcher holds your profile, caches, temporary files and logs. Downloads start in Data\Downloads. You can choose another destination in the Save As dialog.

Close Quiver before moving the folder, unplugging the drive, or installing an update.

To update, install into the same PortableApps folder. To remove Quiver, close it and delete the QuiverPortable folder after saving any profile data you want to keep.
