Quiver Portable

Run QuiverPortable.exe on 64-bit Windows. Quiver keeps your browser profile in the Data folder beside the launcher. Close Quiver before moving the folder, unplugging the drive, or installing an update.

To update, install into the same PortableApps folder. To remove Quiver, close it and delete the QuiverPortable folder after saving any profile data you want to keep.
