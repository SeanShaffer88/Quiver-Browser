          Import from Arc

          Environments

          Group the origins of one app once. Then Ctrl+Alt+E (or Ctrl+Shift+E) cycles local → staging → production, keeping path, query and hash. Leave an origin empty to skip it.

          Command bar

          Must start with http(s):// and contain %s for the query. Search text is only sent when you press Enter on a search result.

            Privacy

            Quiver sends no telemetry, has no account and checks for updates only if you turn that on under Updates. Crash reports stay on this device. These settings apply to all Spaces.

            Cancel requests from other sites to a built-in list of well-known ad and tracker hosts. The list ships with Quiver and is never downloaded. The shield in the toolbar shows how many were blocked on the page; click it to allow ads on that site.

              Shortcuts

              Choose Change, then press the new key combination (Esc cancels). Keys marked “page first” go to the web page first, as in Chrome: in an editor such as Google Docs, Ctrl+B is bold and Ctrl+F is the editor’s own find. Quiver always keeps Ctrl+T, Ctrl+W, Ctrl+L, Ctrl+K, Ctrl+R/F5, F12, Ctrl+J, Ctrl+Tab, Ctrl+PageUp/PageDown (with or without Shift), Ctrl+Shift+T/N/I, Ctrl+1–9 and Alt+1–9.

              Updates

              Off by default. When on, Quiver asks GitHub (api.github.com) once a day for the latest release and shows a notice in the sidebar when a newer one exists. Nothing is downloaded or installed; the notice opens the release page.

              Downloads

              Show Save As for every download. When off, files go straight to your Downloads folder (the Data folder in Quiver Portable) and get a number if the name is taken.

              Tabs

              A link a pinned tab would open in a new tab or window shows in a floating preview over the page instead. Press Esc to close it or choose Open as tab to keep it.

              Tabs below the divider that you haven't looked at for this long move to the archive. Pinned tabs, the tab you're on in each Space and tabs playing sound stay. Type archive in the command bar to search and reopen them. Closing a pinned tab takes it back to its pinned page instead of removing it.

              Local servers

              Lists HTTP servers listening on this machine (netstat + a local request for the page title). Pauses while the window is in the background.
