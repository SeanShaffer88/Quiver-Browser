# Quiver

**Short description (repo / store):** Local-first Chromium browser for developers on Windows: vertical sidebar, isolated Spaces, a developer command bar, environment switching, phone preview and Boosts.

**Topics / tags:** browser, chromium, electron, typescript, developer-tools, windows, local-first, privacy, sidebar-browser, boosts

**Long description:** Quiver is a Windows take on the developer-browser idea behind Flecha. It keeps everything on your machine: no telemetry, no account, no cloud. Tabs live in a vertical sidebar grouped into Spaces (each optionally with its own cookies and logins). One command bar understands `gh`, `npm`, `mdn`, `caniuse`, `so`, `env`, `boost`, and decodes JWTs and Unix timestamps without leaving the device. Group staging and production origins once and jump between them with a shortcut while path and query are preserved. Preview any page in a 393 px touch-emulated phone view beside the desktop view, spot local dev servers automatically, and apply your own CSS and TypeScript per site.
